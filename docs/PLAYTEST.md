# Final playtest — Andrew and son

Use a fresh run on the actual iPhone, then one desktop/controller run. Start with default graphics, then try lower graphics. Record the device, orientation and any point where the game felt unclear. Studio simulation helps check layout; it does not establish real phone performance.

| Check | Expected result | Note to record |
| --- | --- | --- |
| First opening | Full ten-second scene; no skip control; control returns beside the car | Readable caption? Comfortable camera? |
| HUD | Notebook objective icon and red two-half health circle at the top left; phone details open only when tapped | Does any UI cover the movement stick, jump or view? |
| Entrance | Door opens, then walking inside drops the beam | Was the cause and escape goal clear? |
| Staff note | Explains locked exit/power/key; no drink-prevention instruction | Can you open, read and close it? |
| Cellar | Floor chevrons and lit controls, with no reading overlay | How long did finding the controls take? |
| Puzzle | Discover order through lights/feedback; wrong/repeated switch resets; early main pull preserves progress | Was feedback enough to recover? |
| Awakening | Monster visibly framed; first view mandatory; safe return to control | Was he visible on iPhone? Any wall clipping? |
| Hunt | Corners do not instantly defeat pursuit; a proper break of sight allows escape | Any unfair tracking, traps or trivial loops? |
| Bell | Rings before/after awakening; distraction respects cooldown | Audible, spatial and not painfully loud? |
| First catch | One half empties; hold/release; usable escape window | Did the recovery feel long enough? |
| Second catch | Full defeat, then reset with two halves and hidden key | Any stuck camera or controls? |
| Key search | Key visible on the selected dresser/office desk after power | Search duration; room numbering/readability? |
| Courtyard/car | Exit opens, route remains clear, boarding starts drive-away | Can you see where to run under lightning? |
| Repeated scenes | One-second hold fills a circle; releasing early cancels | Does a quick tap accidentally skip? |
| Boundary | Distant grounds stop exploration before a floor edge | Any invisible collision inside normal routes? |
| Replay/reset | Correct objectives, full health, clean camera/input | Try resetting during arrival, reveal, hold and drive |

Record total run time and approximate time spent on the puzzle, search and courtyard. The narrative target is 8–12 minutes, not a timer enforced by the game. Change difficulty after observing an ordinary full run rather than judging from automated teleports.

For each issue, capture: what you tried, where you stood, what you expected, what happened, and whether it repeats. A short screen recording is ideal for camera/touch problems.

Release decisions still need human judgement on comfort, sound balance, readability and fun; passing scripts cannot answer those questions.
